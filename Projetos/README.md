# projetos

Pequenos projetos em JavaScript que juntam varios conceitos (lacos, condicionais, funcoes, entrada de dados) em um programa jogavel no terminal.

## Conteudo

| Arquivo | Descricao |
| --- | --- |
| `pedra_papel_tesoura_computador.js` | Jogo de Pedra, Papel e Tesoura contra o computador (jogada aleatoria) |
| `pedra_papel_tesoura_dois_jogadores.js` | Versao do mesmo jogo para dois jogadores humanos |

## Como executar

```
node pedra_papel_tesoura_computador.js
```

> Usa `prompt-sync` para ler a escolha do jogador via terminal.
