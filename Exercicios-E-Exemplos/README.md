## 📖 Sobre

Este repositório documenta minha **progressão em programação**, desde os primeiros passos até conceitos mais avançados. Aqui você encontrará:

- 📝 **Exemplos de Aula** — Códigos comentados aprendidos durante as aulas
- 🎯 **Exercícios Práticos** — Desafios resolvidos para consolidar o aprendizado
- 🔧 **Projetos** — Aplicações práticas combinando múltiplos conceitos

Conforme avanço no curso, novos temas e linguagens (JavaScript, Python, SQL) são incorporados ao repositório.
