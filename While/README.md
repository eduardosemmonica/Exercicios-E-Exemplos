# while

Exercicios com lacos de repeticao `while` e `do...while` em JavaScript.

## Conteudo

| Arquivo | Descricao |
| --- | --- |
| `exemplo1.js`, `exemplo2.js` | Exemplos de aula sobre a sintaxe do `while` / `do...while` |
| `exercicio1.js` a `exercicio5.js` | Exercicios praticos de fixacao usando lacos de repeticao |

## Como executar

```
node exercicio1.js
```
