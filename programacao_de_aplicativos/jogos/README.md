# jogos

Pequenos jogos de terminal desenvolvidos como projeto de aplicacao dos conceitos de programacao (lacos, condicionais, funcoes, leitura de entrada do usuario).

## Conteudo

| Pasta | Descricao |
| --- | --- |
| [`monstrinho/`](./monstrinho) | Jogo "Batalha contra o Dragao" em JavaScript - o jogador enfrenta um dragao controlando vida e ataques via terminal |
| [`snake/`](./snake) | Jogo da cobrinha (Snake) em Python |

## Como executar

```
node monstrinho/jogo.js
python snake/snake.py
```
