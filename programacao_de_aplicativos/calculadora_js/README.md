# calculadora_js

Projeto de uma calculadora em JavaScript, dividida em modulos - cada operacao (soma, subtracao, multiplicacao, divisao) fica em seu proprio arquivo e e importada pelo arquivo principal.

## Conteudo

| Arquivo | Descricao |
| --- | --- |
| `calculadora.js` | Arquivo principal - importa as funcoes de cada operacao e exibe o resultado no terminal |
| `soma.js` | Funcao de soma |
| `subtracao.js` | Funcao de subtracao |
| `multiplicacao.js` | Funcao de multiplicacao |
| `divisao.js` | Funcao de divisao (trata divisao por zero) |

## Como executar

```
node calculadora.js
```
