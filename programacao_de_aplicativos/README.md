# programacao_de_aplicativos

Projetos maiores, que juntam varios conceitos do curso em uma aplicacao (em vez de exercicios avulsos).

## Conteudo

| Pasta | Descricao |
| --- | --- |
| [`calculadora_js/`](./calculadora_js) | Calculadora em JavaScript dividida em modulos (soma, subtracao, multiplicacao, divisao) |
| [`calculadora_compartilhada/`](./calculadora_compartilhada) | Calculadora em Python usada em atividade de git compartilhada com colegas |
| [`jogos/`](./jogos) | Jogos de terminal (Batalha contra o Dragao em JS, Snake em Python) |
| [`projetos_no_papel/`](./projetos_no_papel) | Rascunhos e ideias de projetos em Python, ainda em fase de estudo |
