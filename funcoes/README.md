# funcoes

Exercicios sobre criacao e uso de funcoes em JavaScript: declaracao de funcoes, parametros, retorno de valores e arrow functions.

## Conteudo

| Arquivo | Descricao |
| --- | --- |
| `funcoes_exemplo.js`, `funcoes_exemplo1.js` | Exemplos de aula sobre sintaxe basica de funcoes |
| `arrow_functions_exemplos.js` | Exemplos de arrow functions (`=>`) |
| `exercicio.js` a `exercicio20.js` | Exercicios praticos de fixacao, com uso de `prompt-sync` para entrada de dados via terminal |

## Como executar

```
node exercicio.js
```

> Alguns arquivos usam a biblioteca `prompt-sync` (instalada via `npm install` na raiz do repositorio).
