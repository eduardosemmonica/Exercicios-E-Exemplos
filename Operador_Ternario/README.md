# operador_ternario

Exercicios sobre o operador ternario (`condicao ? valorSeVerdadeiro : valorSeFalso`) como alternativa mais enxuta ao `if...else`.

## Conteudo

| Arquivo | Descricao |
| --- | --- |
| `exemplos.js` | Comparacoes lado a lado entre `if...else` e operador ternario (aprovacao por nota, par ou impar, etc.) |
| `exercicio1.js` | Exercicio pratico de fixacao |

## Como executar

```
node exemplos.js
```
